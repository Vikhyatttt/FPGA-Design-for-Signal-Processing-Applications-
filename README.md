# FPGA Development for Signal Processing and Compute Architectures

This repository showcases a collection of **FPGA-based hardware accelerators** and **digital signal processing (DSP)** modules implemented using **Verilog** and **Xilinx Vivado**. Each design demonstrates real-world concepts used in **communication systems**, **AI hardware acceleration**, and **SoC development**.

## Overview
The project integrates algorithmic modeling, RTL design, and post-synthesis verification for high-performance FPGA-based compute blocks. Modules are implemented, synthesized, and verified on Xilinx toolchains to evaluate **latency, throughput, resource utilization, and power efficiency**.

### Key Implementations
- **CORDIC Processor:** Trigonometric and vector rotations for coordinate transformations  
- **FIR & IIR Filters:** Parameterized digital filters optimized for area and timing closure  
- **FFT Core:** High-throughput implementation of N-point FFT for spectral analysis  
- **Viterbi & Kalman Decoders:** Probabilistic estimators and error-correction modules  
- **Systolic Array Accelerator:** Parallel matrix-multiply engine for CNN inference  

## Results
Each design includes:
- Schematic, RTL, and post-synthesis results  
- Timing and power analysis (Vivado reports)  
- Resource utilization and frequency scaling studies  

## Tools & Technologies
Vivado · Verilog HDL · MATLAB/Simulink · ModelSim · Xilinx FPGA Boards  

## Industry Relevance
This work reflects **industry-standard FPGA design workflows** used in **AI accelerators, communication systems, and edge-compute SoCs**. It highlights proficiency in **RTL design, DSP architectures, power–performance tradeoffs, and verification** across complex hardware modules.
